# MD-A17：控制端场景工作台与响应式 UI

## 状态

控制端场景工作台、分组设备选择和移动端必要控制已实现。`npm test` 与 `npm run check` 均为 57/57，Android 104 项测试、Lint 和 debug 构建通过；主任务已复核 6 个浏览器视口及 CRUD、分组选择、多会话拖拽、预设管理和 PNG 导出。local/display 角色保留本地快速调节、快捷预设、锁定/退出和同步流程，不展示场景编辑区；Android 真机安全区、软键盘和 OEM 差异未测。

## 目标

在保持 MarkerDeck 现有投放协议和设备行为的前提下，为桌面/平板控制端提供可持续使用的场景工作台：顶栏承载快速连接、新建场景和场景管理；左侧管理分组设备与投放选择；中间按场景尺寸等比例布局接收页面；右侧继续提供预设、参数和导出。手机控制端只保留必要的设备选择、场景摘要、批量锁定和既有底部预设入口。

## 已观察问题

- 控制端缺少场景维度，设备选择、参数和预设堆叠在同一滚动路径中，桌面/平板空间利用率低。
- 同一物理设备的多投放会话、跨分组选择和部分选中状态难以识别；锁定入口与设备选择距离过远。
- 平面图需要按真实宽高比例保存接收页面位置，设备心跳刷新不能打断正在进行的拖拽。
- 场景表单的新建、编辑、复制、删除和 Enter 提交缺少清晰状态边界，浏览器存储异常时也应回退到可用默认值。
- 手机不适合承载完整平面图和重复的快速预设网格，现有必要控制应在首屏和可预测的滚动流中可达。

## 范围

- 统一控制端工作台的 CSS 变量、容器、按钮、焦点、禁用和错误状态，保留既有业务 DOM ID 与模块加载方式。
- 顶栏提供快速连接、新建场景和场景管理；左侧设备区提供场景选择和当前选择的批量远程锁定入口。
- 设备按物理设备和分组组织，支持组全选、部分选中、多组选择、多会话展开/收起；收起组后保留会话选择状态。
- 增加版本化浏览器 `localStorage` 场景文档，保存场景名称、宽高/单位和接收页面归一化坐标；支持创建、编辑、复制、删除、重命名、表单校验和 Enter 提交。
- 中间平面图按场景真实宽高等比例显示缩略卡，支持缩放、拖拽和场景边界保护；设备列表刷新只更新现有节点状态，不替换进行中的拖拽节点；卡片在挂载后再绘制缩略图，并在尺寸变化时重绘。
- 手机端隐藏完整平面图编辑器与重复快速预设网格，保留设备选择、场景摘要、批量锁定和现有底部预设面板；分组列表改为单列紧凑布局并遵循安全区。
- local/display 角色不初始化场景控制台，不展示平面图、场景选择、场景管理或远程目标详情，保留原有本地快速调节、快捷预设、锁定/退出和同步语义。
- 同步 Node 与 Android WebView 静态资源白名单和检查脚本，确保 `markerdeck-scenes.js` 可通过现有 HTTP/Android Host 加载。

## 非目标

- 不改设备发现、HTTP/SSE、锁定 ACK、状态同步、预设、PNG/MP4 导出协议，也不改变 `deviceId`、`sessionId` 或现有导出文件格式。
- 不把场景文档上传服务端；场景只保存在当前浏览器的版本化 `localStorage` 中，不承诺跨设备同步。
- 不重写 Android 原生设置页、启动页或投放壳，不增加 Android 原生 UI；Android 只同步共享网页静态资源白名单和对应 HTTP 测试。
- 不引入前端框架、构建工具、远程字体、图标 CDN 或网络运行时依赖，不在本任务内发布 Release。

## 技术边界

- `src/web` 继续由桌面 Node、Electron 与 Android assets 共用，可直接通过 HTTP 和 `file://` 加载；`markerdeck-bootstrap.js` 仍是唯一装配入口。
- 场景初始化只在控制模式执行，local/display 页面保留原预设 DOM 与行为；设备刷新、导出和锁定模块保持原事件路径。
- 场景宽高接受 `0.01–100000`，归一化坐标始终限制在 `[0, 1]`；平面图在可用视口内按真实比例适配，极端比例提示卡片可用空间有限，不静默修改比例。

## 验收标准

- 桌面/平板控制端在 `1440x900`、`1200x800`、`1024x768` 和 `820x1180` 下无横向溢出、三列/两列区域不重叠，设备区、平面图、预设/参数均可独立滚动；`4 × 10` 等纵向场景仍保持真实比例并能在视口内适配。
- 场景管理可通过按钮和真实表单 Enter 创建/保存；新建字段不会被当前场景覆盖，点击已有场景退出新建模式；复制深拷贝坐标，删除最后一个场景安全回退，非法 JSON 或存储异常回退默认文档。
- 设备分组全选、部分选中、多组选择、折叠保留选择、多会话展开和场景底部取消选择/批量锁定均更新同一选择集合；设备心跳期间拖拽节点不消失且释放后坐标持久化。
- 手机控制端在 `390x844`、`360x800` 下不显示完整平面图编辑器或重复快速预设网格，设备分组单列排列，选择/锁定/预设入口不遮挡设备卡片和安全区。
- local/display 页面不移动预设 DOM、不打开隐藏的控制端预设覆盖层；控制端场景模块 CRUD 完成后无未绑定的状态更新调用或入口级异常。
- `npm test`、`npm run check`、Android `:app:test :app:lintDebug :app:assembleDebug` 与 `git diff --check` 通过；浏览器截图、Android 真机和 OEM 差异单独记录，未测环境不写成已通过。

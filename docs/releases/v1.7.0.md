# MarkerDeck v1.7.0

发布日期：2026-09-05

## 更新内容

- **场景工作台**：桌面与平板控制端新增顶栏快速连接、新建/管理场景，左侧按分组选择设备，中间按真实场景比例布局接收页面，右侧集中预设、参数和导出。场景尺寸与接收页面归一化坐标按版本保存在当前浏览器；手机控制端保留必要选择、批量锁定和底部预设入口。
- **手机被控端快速调节**：local/display 手机解锁后首屏直接提供背景颜色、总体亮度、十字颜色和大小等常用参数，复用移动预设栏与既有预设管理。锁定或远程锁定会关闭并清理移动入口，竖屏与横屏均保留可滚动的触控区域。
- **Android 本机作为宿主**：控制 WebView 增加状态栏和刘海安全区顶部 inset；local/display 投放继续使用沉浸式窗口。Android 模式页仍提供本地投放、连接局域网宿主和本机作为宿主三个入口，宿主服务由前台服务保持。
- Node、Android Host、网页与导出继续使用现有 HTTP、SSE、设备身份、锁定 ACK、状态同步和文件格式；未新增服务端协议或 Android 原生业务 UI。
